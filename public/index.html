ML Algorithms

Five algorithms — supervised, ensemble, and unsupervised — applied to the salary prediction task.

01
Supervised

Linear Discriminant Analysis

Finds a linear combination of features that best separates income classes (≤$50K vs >$50K). Used as the classification backbone to calibrate regression output.

— accuracy
02
Regression Tree

Decision Tree Regressor

Partitions the feature space by income-relevant splits (occupation, education, hours). Maximum depth of 12 prevents overfitting while capturing non-linearities.

— R² score
03
Regularized

Ridge Regression

L2-penalized linear regression (α=10) reduces multicollinearity between highly correlated features like education level and occupation. Provides the most interpretable coefficients.

— R² score
04
Ensemble ★

Bagging Regressor

50 bootstrapped Decision Trees trained on 80% random subsamples. Reduces variance and achieves the highest R² through model averaging — the primary prediction backbone.

— R² score · — MAE
05
Unsupervised

DBSCAN Clustering

Density-Based Spatial Clustering identifies natural income groups without predefined labels. Detects outliers (workers with atypical capital gains or unusual work patterns).
